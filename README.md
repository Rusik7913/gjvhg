# NEON RUSH 3D v2

A polished Android endless-runner prototype inspired by the lane-based runner genre.

Features:
- 3-lane pseudo-3D perspective
- Neon city, sunset sky and animated skyline
- Swipe left/right to change lanes
- Swipe up to jump
- Swipe down to slide
- Coins and obstacles
- Speed increases over time
- Pause and game-over screens
- Local best-distance and coin save
- Low / Medium / High quality setting
- Android 8.0+ (API 26+)
- Designed for phones and tablets with responsive scaling

## Build
Use Android Studio or GitHub Actions.

The GitHub Actions workflow is in `.github/workflows/android.yml`.
